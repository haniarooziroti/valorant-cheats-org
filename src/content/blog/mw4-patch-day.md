Every game patch can change things that third-party software depends on. Launching blindly right after an update is how people hit avoidable problems.

## 1. Check the status page first

Open the [status page](/status/). If MW4 shows as active, you're clear on our side. If it shows an update in progress, don't launch.

## 2. Give it a few hours

Even after status turns active, consider waiting a bit and reading the [Discord](https://discord.gg/Vu85F8auQS) for reports from other users. Early feedback catches things quickly.

## 3. Update the loader

Close the old loader fully and use the latest version from your access email. Running an old loader against a new build is a top cause of crashes.

## 4. Verify game files

Use your launcher's file check so the game matches what the loader expects. A half-updated install causes strange bugs that look like cheat issues.

## 5. Recheck Windows settings

Major Windows updates sometimes switch off Core Isolation or Secure Boot. Take a minute to confirm all four requirements are still on.

## 6. Start conservative

For your first session after a patch:
- Use fewer features than usual.
- Shrink the aim circle or leave aim off.
- Skip ranked-style play for the first sessions.

## 7. Know when to stop

Errors, crashes or odd permission prompts are a reason to close it and open a ticket on the [support page](/support/).

## Quick checklist

- [ ] Status page shows active
- [ ] Loader updated
- [ ] Game files verified
- [ ] Windows security settings still on
- [ ] Conservative settings for the first session
