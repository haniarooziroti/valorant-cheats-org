Most loader problems have the same handful of causes. Go in this order.

## 1. Check the four Windows settings

HVCI, Core Isolation, TPM and Secure Boot all need to be on. If any are off, nothing else you try will matter. Use the [system requirements guide](/blog/mw4-requirements/).

## 2. Run as administrator

Right-click the loader and choose Run as administrator. Running it normally is the next most common cause of silent failures.

## 3. Antivirus blocks or deletes it

Add an exclusion for the loader's folder. Only do this for the file from your official download. Never whitelist something from a re-upload or a stranger on Discord.

## 4. Check the status page

Open the [status page](/status/). If it shows an update in progress, the loader is being brought in line with a new game build. Wait for it to go active.

## 5. Menu won't open

- Press INSERT while the game window is focused.
- Try borderless windowed mode.
- Turn off other overlays: Discord, GeForce Experience, MSI Afterburner, screen recorders.

## 6. Game crashes on launch

- Verify game files in your launcher.
- Start the game first, reach the main menu, then run the loader.
- Update your graphics drivers.

## 7. Low FPS with visuals on

Turn off skeleton and snaplines, lower the distance cap, and close background apps.

## 8. Still stuck?

Open a ticket on the [support page](/support/) with:
- Your order email
- Windows version
- A screenshot of the exact error
- What you did right before it appeared
